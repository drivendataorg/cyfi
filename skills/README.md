# skills/

This directory contains CyFi's agent skill, `cyfi/SKILL.md`. The skill teaches a coding agent to run the installed `cyfi` CLI with a person: gather their locations and dates, run estimates, and explain the results. It needs no particular harness.

To install it, copy or symlink `cyfi/` into your agent's skills directory, for example `.claude/skills/cyfi/` for Claude Code.

This directory is not packaged with the `cyfi` library.
