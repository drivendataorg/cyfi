# skills/

This directory contains CyFi's agent skill, `cyfi/SKILL.md`. The skill teaches a coding agent to run the installed `cyfi` CLI with a person: gather their locations and dates, run estimates, explain the results, and open the CyFi Explorer. It needs no particular harness.

To install it, copy or symlink `cyfi/` into your agent's skills directory, for example `~/.claude/skills/cyfi/` for Claude Code. The main README's "Using CyFi with AI agents" section has the details.

This directory is not packaged with the `cyfi` library.
